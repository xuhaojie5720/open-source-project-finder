# AShare-Quant (A股开源量化交易与股票操作助手)

`AShare-Quant` 是一个专为 A 股市场设计的开源量化交易分析与股票操作辅助系统。系统结合免费金融数据源 `AKShare`，提供一站式的**实时数据抓取、多因子选股评分、策略历史回测及实盘风控操作提示**。

## 🌟 核心功能

1. **多因子量化选股引擎**：综合技术面（均线多头排列、MACD水上金叉、RSI黄金拉升区、布林带中轨突破）与量能放大进行 0-100 分打分。
2. **股票实盘操作诊断**：自动计算单只股票买卖信号、推荐建仓股数、算算建仓资金占比，并精确算出 5% 止损线与 15% 止盈位。
3. **策略历史回测评估**：支持模拟评估双均线金叉策略在历史数据中的累计收益率、夏普比率、最大回撤与交易胜率。
4. **自选股全自动化扫描**：一键生成自选股票池操作建议排行榜。

## 🚀 快速上手

### 1. 安装依赖
```bash
pip install akshare pandas numpy matplotlib backtesting
```

### 2. 运行主程序
```bash
python main.py
```

## 📁 目录结构

- `config.py`: 项目全局配置文件（初始资金、风控比例、自选股列表）。
- `data_engine.py`: 依赖 AKShare 的数据拉取引擎。
- `strategies.py`: 技术指标计算与多因子评分/信号策略。
- `backtest_engine.py`: 策略回测与绩效报告生成模块。
- `trade_assistant.py`: 实盘操作与股票风控诊断助手。
- `main.py`: 可交互命令行主入口。
